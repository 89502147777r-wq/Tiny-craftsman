## Крючок (лучший — 1)
1. **Перемотка ◀◀**: первый кадр = последний (низко с бортика чаши: белый «парус», коробка, седум, стекло, кант на фоне неба;
   «?» под свободным краем консоли — там, где «должна быть» колонна). С 0,1 с слои уходят сверху вниз, на миг мелькает лес стоек,
   уходит «парус»; 1,4 с — стук, голый павильон из ролика 2; 1,7 с — первая работа крупно.
2. «Последняя стойка» выходит, «парус» висит, «?». Сильнее всего, но петля только если отделка уйдёт в ролик 4.
3. «$ → ?» — счётчик трат; слабый (двигаются только цифры) — идёт в финал.
