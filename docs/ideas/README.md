## Вилла на одной колонне (из шортса хозяина, 35 млн, 2026-11-04)
Три этажа консолями на одной колонне Y: подошва → колонна → перекрытия с консолью → кладка → белый фасад → вид
на закате. Один ракурс на этап, прыжки во времени, минимум надписей, 1,5–2,5 мин. Нужно: колонна Y (две наклонные
ветви — есть наклон колонн), консоль перекрытия на сваях есть. Честно: на настоящей стройке так не строят без расчёта —
можно подать как «реально ли это?», реалист проверит.

### Дизайн виллы (утверждён хозяином 2026-11-04)
Примерно как картинка хозяина «Single column supported floating home»: 3 этажа консолями на одной ножке; ножка —
колонна в стеклянной шахте лифта с кабиной и ажурной стальной решёткой; кирпичная шахта насквозь до крыши; стены —
кирпич и светлые блоки, глухие куски чередуются слева/справа; окна в пол; тёмный металлический кант по краям плит;
зелёная кровля с террасой и стеклянным ограждением; внизу бассейн вокруг ножки, газон, дорожки, растения, свет, забор.
Не делаем пока: винтовую лестницу с площадкой, очаг/костёр, бассейн на крыше. Финал: облёт → аплодисменты → порыв
ветра → ножка трескается у основания → дом падает в бассейн → «Почему настоящая — такая» → правильный дом (ствол 1,2 м,
фундамент больше дома) стоит.
