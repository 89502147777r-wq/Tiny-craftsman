# Послание самому себе (новая сессия)

Tiny Craftsman — браузерная 3D-игра-стройка на Three.js для телефона: от разметки и
котлована до кровли, фасада, благоустройства и интерьера («Готово»). Хозяин проекта
пишет по-русски с телефона, присылает скриншоты и экспорты проекта (`*.json.gz`).

## Правила хозяина (постоянные)
- Отвечать **по-русски**, коротко, без воды. Делать без вопросов; спрашивать только о
  настоящих развилках дизайна.
- Всё **реалистично, «как на настоящей стройке»**, с плавной пошаговой анимацией работ.
- Ассеты только **CC0 или CC-BY**, каждый — в `CREDITS.md` (файл, модель, автор, лицензия, ссылка).
- **Никаких российских/советских машин и брендов.**
- Интерфейс двуязычный: на каждую новую русскую строку — перевод в `src/i18n/en.js`
  (иначе падает тест «English»). Строки с меняющимися числами — без словаря, по `LANG`,
  с `data-notr`.
- «Делай с запасом»: исправлять причину, а не симптом, чтобы не повторялось; добавлять тест.
- Токен Sketchfab — только в секретах GitHub (`SKETCHFAB_TOKEN`), в чат не выводить.

## Как выпускать сборку
1. Поднять `BUILD` в `src/config.js`.
2. `timeout 900 node tests/quick.mjs` — все тесты должны пройти (сейчас 68/68, ~11 мин).
   Тест «sand: … undo» изредка мигает — перезапустить.
3. Ветка от свежего main: `git fetch -q origin main && git checkout -q -B build-NNN origin/main`
   (локальные правки: `git stash -u` → checkout → `git stash pop`). Никогда не force-push.
4. Коммит (по-английски, что и почему) с трейлерами:
   `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` и
   `Claude-Session: <ссылка текущей сессии>`.
5. PR через `mcp__github__create_pull_request` (owner `89502147777r-wq`, repo `Tiny-craftsman`),
   тело заканчивается «🤖 Generated with [Claude Code](https://claude.com/claude-code)» + ссылка
   сессии; затем `mcp__github__merge_pull_request` (squash). Деплой на Pages — сам.
6. Отчёт хозяину: что было не так, что сделано, цифры, что осталось.

## Экономия лимита (хозяин жаловался)
- Скриншоты и картинки дорогие: снимать только когда без них нельзя; одна сводная картинка
  лучше десяти. Headless-рендер большого дома в контейнере идёт 2–4 мин на кадр (swiftshader).
- Не перечитывать большие файлы целиком — `grep -n`, `sed -n` по строкам.
- Длинные прогоны — в фоне (`run_in_background`), ждать через until-цикл, не через sleep.

## Устройство (главное)
- `src/main.js` — приложение `app` (доступно как `window.__tc` для тестов): цикл кадра
  (`frame`/`step`), сохранение по частям в IndexedDB, `warmUp()` (прогрев шейдеров),
  адаптивное разрешение (только пока палец работает, ≥1,5×), диагностика для меню.
- `src/core/objects.js` — хранилище записей `{type, …}`; `journal` — undo/redo.
- `src/world/walls.js` — `WallView`: кладка (instanced блоки/кирпич), окна/двери, фасады,
  кровли, отмостка. При кладке блоков тяжёлое (фасад, крыша, засыпка) откладывается до паузы
  руки (`_late`); лист кровли не перестраивает стены (только сдвиг мауэрлата — `_plateKey`).
- `src/tools/*Tool.js` — инструменты; `wallTool.js` — стены, окна, фасад, кровля и т.д.
  (`wallKind`); меню — `src/ui/ui.js` (`GROUPS`, `chips()`).
- Окна/двери/ворота — 3D-модели `assets/models/openings/*.glb`, подгонка 9-slice в
  `src/world/openingKits.js` (`wantKit` грузит модель лениво); монтаж (пена, ленты, отлив,
  подоконник, направляющие ворот) — процедурный в `windows.js`/`doors.js`/`garage.js`.
- «Готово» — `src/world/interior.js`: план этажа из кладки (сетка на 1,2 м и над дверями,
  заливка снаружи), перегородки, комнаты, мебель (`furniture.js`, модели
  `assets/models/interior/`), гараж — комната с гаражными воротами (машина, верстак, стеллажи…).
  Строится в `gardenView.js` только при изменении окон/кладки/крыши, удаляется целиком.
- Экстерьер: только освещение фасада и козырьки (крыльцо из меню убрано, код жив).
- Камера — кнопка наверху (между «вперёд» и меню); «Готово» — отдельная кнопка в нижнем ряду.

## Производительность (что уже выяснено, не повторять ошибок)
- Тени дорогие: рисуются только при движении/работе; прожектор даёт тень только ночью;
  арматура без теней. Интерьер склеен по материалам, без теней.
- После загрузки `renderer.debug.checkShaderErrors = false` (иначе стопор на каждом шейдере);
  `gl.getError` раз в 15 с.
- Холсты текстур — с `willReadFrequently` (`canvas()` в `world/roof.js`).
- Профилирование: CDP Profiler через Playwright (скрипты были в scratchpad: `ux/prof*.mjs`) —
  при необходимости написать заново.
